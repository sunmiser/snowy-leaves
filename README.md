Snowy leaves is a mod I made that gives leaves more features like adding a snow covered leaves overlay that texture picks the snow texture from terrain.png so it works with texturepacks, the leaves texture will turn white like in bedrock over time when it snows, birch and spruce and their own colormaps that are solid colors of the hardcodded color in game but can be swapped out with an actual color map. All of these features and be changed in the settings to ur liking. M:OE stands for Minecraft: Oldschool Edition.
